# Technical Capability Domain - Capability Areas

Extracted from: MITA 4.0 Capability Reference Model Document for MGB-TA Subgroup Update-0426.docx

Table 5. Technical Capability Domain

## Technology Infrastructure Management

### Compute and Storage

**Definition:** Provides the State Medicaid Agency (SMA) with the ability to provision computing resources for the Medicaid Enterprise System (MES) and manage the storage of data and files, with backups and retention in accordance with regulatory compliance requirements.

**Topics:**

- Servers
- Storage
- Backups
- Retention

### Networking and Technical Recovery

**Definition:** Provides the SMA with the ability to establish secure connections between MES environments, and external systems and partners, monitor network traffic, and adjust the network through failover and recovery during peak usage or outages.

**Topics:**

- Networking
- Communications
- Disaster Recovery
- Failover

### Identity, Access, and Consent

**Definition:** Provides the SMA with the ability to manage how someone logs in, what role and permissions they have, and how identity is verified within the MES, and gather members’ consent and sharing preferences.

**Topics:**

- Roles Based Access Control
- Identity Proofing
- Consent and Sharing Preferences

### Security Protection and Monitoring

**Definition:** Provides the SMA with the ability to secure and protect sensitive and confidential Medicaid and healthcare information in the MES, prevent unauthorized access, detect unusual activity, log and remediate events, and support audits to comply with regulatory compliance requirements.

**Topics:**

- Encryption
- Monitoring of Activities
- Event Logging
- Audit and Compliance

### System Operations and Monitoring

**Definition:** Provides the SMA with the ability to analyze the MES health, performance, and availability, and perform steady-state operational processes to maintain and support the MES and its environments.

**Topics:**

- Monitoring of Performance
- Availability
- MES maintenance

### Development, Testing, Release, and Security Compliance

**Definition:** Provides the SMA with the ability to create, update, and version source code and scripts, test changes, resolve defects, and promote through pre-production and production MES environments with security checks incorporated.

**Topics:**

- Source Code and Script
- Version Control
- Bugs and Defects
- Deployment and Security Checks

## Application Management

### API, Messaging, and Integration

**Definition:** Provides the ability for the SMA to facilitate integration and connectivity between MES applications through scheduled or real-time events and establishes connections with the Centers for Medicare and Medicaid Services (CMS), Managed Care Organizations (MCOs), providers, and other Medicaid partners or external systems.

**Topics:**

- APIs and Interfaces
- Alerts and Events
- Common Formats (FHIR, X12, REST)
- Secure connections with CMS, MCOs, and Providers

### Application Hosting and Platform Services

**Definition:** Provides the ability for the SMA to host Medicaid applications in managed environments within the MES, and leverage and reuse common services to avoid duplication and redundancy.

**Topics:**

- Hosting Environments
- Shared Resources

### Business Rules and Workflow

**Definition:** Provides the ability for the SMA to automate Medicaid business processes and document and share business rules human readable and system formats to support transactions.

**Topics:**

- Workflows
- Business Rules

### Modular Architecture

**Definition:** Provides the ability for the SMA to decompose Medicaid applications into smaller, manageable components that are easier to modify, update, or replace, without impacting the entire Medicaid application or MES.

**Topics:**

- Modularity
- Scalability
- Ease of Replacement

### User Interface and Session Management

**Definition:** Provides the ability for the SMA to design Medicaid applications that are easy for internal and external users to interact with and perform activities, and work across different devices and browsers, and accessibility tools, including maintaining user activity within the Medicaid application so users can continue or complete their activities.

**Topics:**

- User-Friendly Design
- Accessibility
- Continuity of User Activities
